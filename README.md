# Gabriel Gondim — Portfolio

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro, sem frameworks ou dependências externas.

## Sobre

Site criado para apresentar minha trajetória profissional como Software Engineer, com foco em desenvolvimento full-stack utilizando Java/Spring Boot no backend e Angular no frontend.

## Seções

- **Hero** — apresentação com animação de texto digitado e avatar com órbitas
- **Sobre** — resumo profissional e estatísticas (34+ repositórios, 4 anos de experiência, 6 empresas)
- **Experiência** — timeline completa com todas as empresas onde atuei
- **Skills** — barras de progresso animadas por categoria (Backend, Frontend, Banco de Dados, Cloud/DevOps)
- **Projetos** — cards com os principais repositórios do GitHub
- **Contato** — links diretos para email, GitHub e LinkedIn

## Tecnologias do site

- HTML5 semântico
- CSS3 com variáveis, animações e responsividade
- JavaScript vanilla (sem frameworks)
- Google Fonts — Inter + Fira Code
- Canvas API para partículas animadas no fundo

## Stack profissional destacado

**Backend:** Java · Spring Boot · Kotlin · RabbitMQ · Python · REST APIs  
**Frontend:** Angular · TypeScript · HTML/CSS  
**Banco de dados:** PostgreSQL · MySQL  
**Cloud & DevOps:** AWS · Docker · CI/CD · Git

## Como rodar

Basta abrir o arquivo `index.html` no navegador — não requer servidor ou instalação.
